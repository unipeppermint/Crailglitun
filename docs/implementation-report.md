- 对象、方式、限制从兼容任务中抽样。环境、时长与锁定共同筛选，近期任务和近期完成任务降低权重。无候选时保留条件并给出调整提示。

- 草稿在照片、裁切、排序、配文变更后保存；离开页面、进入后台时补充提交。编辑已有作品使用独立草稿，确认后在同一数据库事务内更新原作品并移除编辑草稿。
- 真实空状态、本地作品列表、草稿列表、主题完成进度、作品编辑/删除、独立同题再创作、选择两次同题作品进行对照。

## 数据与实现边界

元数据由程序化 Core Data 模型保存，记录包含任务快照、照片相对路径、裁切范围、配文与完成状态。素材位于 Application Support/TurnScene，缩略图位于 Caches/TurnScene；媒体读写、解码和导出使用专用后台串行队列，相机使用独立会话队列。Core Data 页面元数据使用主 context。

导入图片规范化方向并保存最长边不超过 2800 px 的 JPEG 源副本；导出宽度为 1600 px。裁切参数独立保存，不反复改写源副本。未引用的素材在记录变更及下次启动时回收；缓存清理不触及源素材或数据库。读写失败不会伪报成功，损坏的元数据不会触发自动清库。

首版为固定浅色主题，无账号、后台、社区、云同步、内购或第三方依赖。正式支持邮箱未提供，所以反馈页只说明当前渠道状态，没有假邮箱或自动发送行为。

## 已实际检查的界面与流程

在专用 TurnScene QA（iPhone 17 Pro / iOS 26.5）及 TurnScene SE QA（iPhone SE 第三代 / iOS 26.5）进行检查：

- 首页、主题馆、主题任务、任务详情、创作、裁切、版式预览、作品详情、设置和存储管理均实际打开查看。
- 锁定方式后重转仍保持三格；全锁定时禁用转动；全锁定后缩短时长出现无匹配任务提示。
- 手选菜单显示经当前环境、时间与锁定筛选的对象。
- 系统照片选择器真实导入三张测试素材；槽位进度从 0/3 到 3/3；裁切范围保存进数据库。
- 三张照片在进程终止、安装新构建并重启后恢复，中文配文在退出编辑再进入后恢复。
- 完成确认后保存一件明确标注 QA 的测试作品，确认数据库中的三张素材文件均存在。
- 查看导出预览，实际打开生成的 JPG 样张检查中文与三格排版；单件导出成功展示系统分享面板，并取消分享，没有发送给任何第三方。批量导出选择页已检查，选中一件作品后数量从 0 正确更新为 1。
- 只有一件作品时显示同题引导，点击再创作后建立独立 0/3 草稿，原作品仍保留。
- 存储管理从真实文件统计用量，清缓存后提示完成，原素材与作品、草稿保留。
- 最大辅助字号下发现并修复筛选控件横向挤压；辅助字号改为纵向筛选，滚轮文字限制在可读范围，页面可纵向延伸。
- iPhone SE 小屏能够从首页任务进入详情，并执行滚动范围内的开始创作按钮。
- 模拟器无相机时呈现明确提示，仍可导入照片完成创作。

## 滚轮图片适配修正（2026-09-30）
修复三种创作方式全部映射到同一三格胶片的问题。单图配文使用单张照片和两行配文提示，双图对照使用两个独立并排相框，三格故事使用三张连续照片胶片。图片由 UIKit 组合现有主题照片，不新增素材依赖。照片采用等比填充和框内裁切，三种构图使用统一透明画布并缓存。
