当前视觉基准是轻量 Slot 滚轮与设置页版本。这里汇总原型文件、版本用途和实现时需要补全的交互，避免旧图中的机械拉杆或三环结构重新进入首版。

所有图片均为内置 imagegen 生成的静态视觉原型。它们不是可点击原型，也不是已运行的 UIKit 界面。原图与生成提示词保留在项目 design/prototypes 目录中。

## 首页交互

1. 选择环境和时长，刷新兼容任务范围。
2. 点击转一下，业务逻辑先确定结果，未锁定列随后滚动并依次停止。
3. 全部停止后更新任务预览，点击预览进入详情。
4. 点击列下方锁定按钮，切换该列的锁定状态。
5. 手动滑动未锁定列，吸附到中央并检查组合是否有效。
6. 全部列锁定时，转一下不可触发，显示解锁一列后再转的提示。
7. 无可用任务时保留用户选择，说明需要调整环境、时长或锁定条件。
8. 动画中禁用重入；返回前台时展示已确定结果。

建议完整停轮过程约 1 至 1.5 秒，具体时长以真机体验调整。音效关闭时不发声，触感关闭时不震动。开启减少动态效果时跳过长距离滚动。

## 创作与作品

任务详情进入分步创作。每个照片槽位支持拍摄、导入和替换；当前步骤与已完成步骤用文字和图标共同表达。完成后进入编辑预览，保存为作品。

草稿入口展示最新未完成任务；作品集也提供查看草稿的路径。替换照片、编辑文字、调整顺序后要保存状态。退出创作不应默默丢弃内容。

同题再创作继承任务身份和条件，同时创建新的独立草稿，原作品保持不变。对照页面允许用户选择同题下的两次作品；只有一件作品时给出再创作入口。

## 设置页

入口位于首页右上角齿轮，进入后显示返回按钮，不新增底部 Tab。

| 分组 | 项目 | 默认或行为 |
| --- | --- | --- |
| 交互体验 | 触感反馈 | 开启 |
| 交互体验 | 转动音效 | 关闭 |
| 交互体验 | 动态效果 | 跟随系统，可选择进一步减少 |
| 作品与数据 | 导出作品 | 选择作品后导出成品图片 |
| 作品与数据 | 存储管理 | 展示素材与缓存占用，提供清理缓存 |
| 帮助与关于 | 使用帮助、意见反馈、隐私政策、关于转场 | 按真实内容展示 |

相机、相册权限由系统管理，不在这里制作无法代表系统状态的开关。

## 视觉实现建议

| 项目 | 建议 |
| --- | --- |
| 页面底色 | 米白，参考 #F6F3EB |
| 主文字 | 深灰，参考 #252B29 |
| 主要操作 | 橙色，参考 #EF7046 |
| 选中与辅助状态 | 青绿，参考 #678F87 |
| 字体 | 系统字体，支持较大字号 |
| 图标 | 系统符号搭配少量原创主题插图 |
| 滚轮 | 原生控件和动画绘制，避免把整张原型当背景 |
| 照片 | 用户素材为主，演示图明确区分 |

颜色为设计起点，落地时检查文字对比度。常用操作提供足够大的点击区域，重要信息不能只靠颜色区分。适配较大字号时允许页面纵向滚动，不挤压按钮或遮挡内容。

## 尚待补齐的界面状态

现有四屏图没有覆盖全部功能，开发时仍需补充主题馆最终样式、拍摄执行、作品编辑、作品详情、批量导出和存储管理页面。

还需覆盖首次空状态、无兼容任务、全部锁定、权限拒绝、导入失败、磁盘空间不足、保存失败、导出失败和删除确认。图片中的局部字体或图标细节以实际原生组件和校对后的文案替换。

## 原型验收范围

当前已经交付的是三张整板视觉图及各自提示词。尚未验证真实滚动手感、动画帧率、无障碍朗读、深色模式和各机型布局；这些属于后续原生开发验证范围。
