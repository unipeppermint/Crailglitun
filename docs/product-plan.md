# 转场产品方案

转场是一款用轻量 Slot 滚轮启动生活观察与摄影创作的 iOS 应用。用户用几分钟完成一份具体任务，留下照片与文字组成的作品，并通过同题再创作观察生活中的变化。

产品名称转场和英文名 TurnScene 为工作名称，正式上架前需查重。本方案基于已讨论的方向整理；任务数量、商业化与验证安排是规划建议。

## 用户与使用场景

面向喜欢拍照和记录生活，但经常不知道拍什么、如何表达的普通用户。首版聚焦手机摄影和短配文，不同时扩展到绘画、长篇写作或社交社区。

| 场景 | 用户困难 | 产品提供的帮助 |
| --- | --- | --- |
| 居家空闲 | 熟悉的环境缺少新鲜感 | 从旧物、窗边或细节切入 |
| 午休十分钟 | 时间有限，不想做复杂计划 | 根据时长给出可完成任务 |
| 散步停留 | 有拍摄意愿但缺少主题 | 提供对象、表达方式和限制 |
| 回看生活 | 相册零散，难以形成系列 | 保存任务条件并支持同题对照 |

## 产品价值与差异

核心体验由四部分组成：可执行的条件组合、分步创作引导、完整作品编排、同题再次观察。Slot 结构承担选择与启动任务的作用，用户积累的是自己的创作成果。

常见随机转盘已经提供自定义选项、权重、主题和分享等功能；摄影随机题目也有现成产品。因此，不能把滚轮样式或随机题目单独视为差异化。产品需要把任务质量和创作后的保存、回看做完整。可参考 [Wheel Plus](https://apps.apple.com/us/app/wheel-spin-roulette-picker/id1573133915) 与 [Learn Photo365](https://apps.apple.com/us/app/learn-photo365-photography-assignment-generator/id566645902) 的功能范围。这些是局部参考，不是完整竞品研究。

## 核心流程

1. 用户选择室内或户外，以及 5、10、20 分钟的时长。
2. 点击转一下，三列分别确定观察对象、创作方式和创作限制。
3. 用户可以锁定部分条件，重转剩余条件，也可以手动选择。
4. 查看任务卡中的步骤、时长和所需照片数量。
5. 拍摄或导入照片，按步骤完成任务。
6. 调整裁切、照片顺序、版式和配文。
7. 保存作品，按需导出或分享。
8. 从作品集再次使用同一任务条件创作，形成对照。

首次启动直接进入精选任务体验，不要求注册。进入后台或退出创作后，可以从草稿继续。

## 三列滚轮

| 列 | 含义 | 示例 |
| --- | --- | --- |
| 对象 | 观察什么 | 旧物、光影、圆形、窗边、倒影 |
| 方式 | 如何组织作品 | 单图配文、双图对照、三格故事 |
| 限制 | 增加一个创作条件 | 同一位置、只拍细节、单一颜色 |

原型中的三格是三格故事的短标签，同位置是同一位置的短标签。方式列只展示已经实现的创作形式。

组合示例：旧物、三格故事、同一位置，生成任务旧物的三个瞬间。

任务内容为：选择一件用了很久的物品，拍下整体、磨损和局部细节，再用一句话说明它对自己的意义。

系统只从经过编辑的兼容任务中选择，环境、时长和锁定条件共同限制候选范围。没有可用结果时解释原因，并提示调整条件。手动选择也使用相同的兼容规则。

## 页面与功能

| 页面 | 内容与主要操作 |
| --- | --- |
| 转场 | 环境与时长选择、三列滚轮、锁定、任务预览、继续草稿、设置入口 |
| 主题馆 | 主题浏览、任务示例、室内外筛选、主题进度 |
| 任务详情 | 条件组合、步骤、时长、照片数量、开始创作或换组合 |
| 创作执行 | 当前步骤、拍摄或导入、照片槽位、草稿保存 |
| 作品编辑 | 照片裁切和排序、短配文、版式预览 |
| 作品集 | 已完成作品、草稿入口、系列与同题对照 |
| 作品详情 | 完整作品、编辑、导出、同题再创作、删除 |
| 设置 | 交互偏好、作品导出、存储管理、帮助与关于 |

底部导航仅包含转场、主题馆、作品集。任务详情、创作、编辑和设置通过页面跳转进入。

## 首版范围

首版计划提供 6 个原创主题、约 60 个经过试做的任务。建议主题包括窗边观察、旧物档案、颜色散步、影子地图、几何日常、局部世界。名称与数量需根据实际内容质量调整。

| 范围 | 首版交付 |
| --- | --- |
| 条件选择 | 三列滚轮、按钮触发、锁定与手动选择 |
| 任务规则 | 环境时长筛选、兼容组合、近期重复降权 |
| 创作形式 | 单图配文、双图对照、三格故事 |
| 素材获取 | 原生拍摄、系统照片导入 |
| 编辑与恢复 | 裁切、排序、配文、草稿恢复 |
| 长期记录 | 本地作品集、手动同题再创作与对照 |
| 导出 | 单件及批量作品图片导出 |
| 设置 | 触感、音效、动态效果、存储与帮助 |

社区、多人创作、地图探索、AI 生成图片、账号、云同步、自动回访提醒和复杂修图暂不纳入首版。自动识别或评价照片是否符合任务也不属于首版能力，完成状态由用户确认。

## 设置与数据体验

触感默认开启，音效默认关闭，动态效果默认跟随系统。系统减少动态效果开启时，以静态或轻微过渡展示结果。

用户素材与作品保存在设备内。清理缓存只删除可重新生成的缩略图等文件；删除作品是独立操作，需要清楚说明影响并二次确认。作品导出产生图片文件，不等于可恢复草稿和系列关系的完整备份。卸载应用可能移除本地数据，帮助页需明确说明。

意见反馈可通过系统邮件入口提供，具体联系地址在发布前补齐。首版不为反馈单独建设账户或消息系统。

## 设计方向

使用米白底色、橙色主要操作和低饱和青绿状态色。滚轮使用浅色凹槽、上下渐隐和中央选择区，移除机械拉杆、厚金属边框和灯泡。Slot 特征通过滚动、停轮和锁定体现。

作品页面以用户照片为主体。原型中的旧杯与窗边照片是演示素材，不代表用户已有作品；实现时要设计真实空状态并区分示例内容。

## 商业化与验证建议

建议先验证完整创作流程，再决定一次性解锁高级版式、主题或导出功能的范围和价格。首版技术范围不包含内购，若决定上线收费，应另行补充 StoreKit、恢复购买和商品状态流程。

开发前可邀请小范围用户试做 15 至 20 个任务，观察从看到任务到开始、完成和保存作品的过程。上线后优先关注首次创作完成情况、保存或导出意愿、第二次主动创作。具体数值目标待试用建立基线后确定，不预设未经验证的留存数据。

## 审核呈现

产品应展示真实的原创任务、分步创作和个人作品记录能力。截图与介绍突出完整流程，审核路径无需登录即可体验，预置内容应足够完成一次创作。

苹果的 4.1、4.2、4.3 分别涉及抄袭、最小功能和重复应用。增加 Slot 外观不等于具有实质差异，也不能保证审核通过；需以最终体验和提交时有效规则为准。[苹果审核指南](https://developer.apple.com/cn/app-store/review/guidelines/#design)

## 首版验收

- 新用户无需注册，可以完成一份任务并保存作品。
- 被锁定的条件在重转后保持一致。
- 任何生成的任务都符合当前环境、时长和内容兼容关系。
- 拒绝相机权限后仍可通过导入照片完成创作。
- 离开页面或重新启动应用后，已保存的草稿可恢复。
- 作品可以被编辑、导出，并使用相同条件发起新创作。
- 同题对照关联正确的两次作品。
- 清理缓存不会删除原素材、草稿或作品。
